# DeepSeek 粘贴菜谱配置

1. 用本地编辑器打开项目中的 `backend/.env`。
2. 在 `DEEPSEEK_API_KEY=` 后填写自己的 Key 并保存。不要发到聊天里，不要填进小程序前端。
3. 模型默认 `deepseek-v4-flash`，对应本次核实的 DeepSeek 官方接口名称；如账户不可用，按开放平台支持的型号修改。
4. 重启本地后端。在原后端终端按 Ctrl+C，再运行：

```powershell
python backend/server.py
```

5. 微信开发者工具重新编译，点击“添加菜谱 → 粘贴菜谱 · AI 整理”。
6. 粘贴包含食材和步骤的文字，点击“让 AI 整理”。检查草稿后再确认保存。

`.env` 已被项目 `.gitignore` 排除；文件位于小程序代码目录之外。后端每次请求读取配置，更新 Key 后无需再次重启。首次代码升级仍需重启后端。

调用仅发送当前粘贴文字和固定整理指令，不发送本地菜谱库、清单或聊天历史。点击整理会产生 DeepSeek API 用量。后端不打印 Key、原文或供应商原始错误，不自动重试付费请求。即使客户端超时或离开页面，已发往服务商的调用仍可能计费。

当前为本机模拟器接口，手机无法用 `127.0.0.1` 连接电脑。确认后的菜谱仍存当前设备，不是家庭共享数据库。

搜索菜名需要另行接入联网搜索服务，当前没有实现；DeepSeek 文字整理不代表联网搜索。下厨房专用链接入口已从添加菜单移除。

测试原文（本项目自编）：

> 番茄炒蛋。食材：番茄2个、鸡蛋3个、油适量、盐适量。番茄洗净切块，鸡蛋打散。热锅加油，炒熟鸡蛋后盛出。番茄炒出汁，再加入鸡蛋翻炒至熟透，放盐调味。

验收：应提取两种主要食材的数量及原文步骤；原文未写的份量、耗时应留空。模型可能出错，仍需人工核对。
